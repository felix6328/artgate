# ArtGate 一页 PRD

**产品：** 游戏美术资产语义检索与入库预检工作台。个人项目，评测使用公开许可资产，不是任何游戏项目组的生产系统。

## 用户

- 原画 / 3D 美术：做新武器前用自然语言或概念图找回已有、风格接近的资产。
- TA / 管线负责人：外包提交入库时检查命名、格式、分辨率、面数、glTF 规范；机械问题不应拖到引擎里才发现。
- 外包：交文件前自检。

## 非目标

- 不是个人灵感相册（Eagle / Immich），不做参考图收藏。
- 不自动改网格、不自动减面、不自动覆盖原文件、不自动驳回警告项、不自动删除。
- 不把面数、像素、格式交给模型口算。
- 第一周不做完整三维引擎预览（Three.js），3D 用软件渲染的等轴测预览图。
- 不声称与腾讯或任何项目组合作过。

## AI 边界

| 用工具（禁止模型） | 可用模型（默认不阻断） | 必须人定 |
| --- | --- | --- |
| 面数、贴图宽高、是否 2 的幂次、格式、体积、glTF 规范、必选通道是否缺失 | 文件名与画面是否一致、是否偏离风格参考板（结构化 JSON + 置信度） | 最终美术方向、审美是否过关、是否入库 |

已经精确知道资产 ID 或路径：走元数据查找，不绕向量。VLM 超时或低置信：降级为仅规则结果 + 待人工，不编视觉评语。

## 默认策略（block / warn）

- **block** 仅限确定性规则失败（命名、格式、体积、对该类型强制的 POT、面数超预算、官方校验器 **error**）。校验器 **warning 不 block**。
- **warn** 为默认的视觉项。只有误拦率低于项目事先约定门槛后，才允许把某视觉项升为 block，升之前必须再跑误拦率。
- 工具崩溃：该项标「工具失败，待人工」，不影响已跑完的规则，**不得改由 LLM 替代**。
- 所有提交默认进入人工确认队列；通过或申诉通过后才入可检索库。改判原因必填。

## 平台化

引擎一套，规范是模板。两套 YAML：

- 模板 M（`stylized_mobile`）：风格化手游低模，命名 `m_*`，面数预算按本仓库 Kenney 子集实测分布设定（max=1660，p95=880），贴图上限 2048，不强制 PBR 通道，不允许 ktx2。
- 模板 R（`realistic`）：写实，命名 `r_*`，面数与贴图上限更高（4K），贴图套装要求 albedo / normal / roughness，允许 ktx2（本评测集未覆盖真实 KTX2 样本）。

2 的幂次对 **texture 类型和 3D 模型贴图**强制，对 2D UI / 精灵不强制——UI 经常不是 POT，一刀切会误拦。这是产品判断。

项目之间资产默认隔离。检索是「结构化过滤 + 语义相似」，不是纯向量。

## 指标定义（先定义再填数）

- 检索：Recall@5、**Recall@10**、nDCG@10、MRR；中英文分开；对照文件名搜索。
- 预检规则层：各检查项 Precision / Recall / F1；误拦率（合格资产被 block）；漏放率（应 block 却通过）。
- 预检视觉层：单独报，不和规则层混成一个准确率。无 API 则不报。
- 体验：单次检索 P95、单资产规则预检 P95。本地机器写清楚。
- 数字一律以 `eval/results.md` 的实测为准，未测不填。
