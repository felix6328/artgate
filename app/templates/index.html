预检 · 检索 · 确认
规则层用官方工具算死数值；VLM 只做视觉建议，默认警告；通过后才入可检索库。
这是个人项目，评测资产来自 Kenney / Poly Haven / Khronos 公开许可，不是任何游戏项目组的生产数据。

语义检索

先按项目 / 类型 / 格式 / 面数过滤，再在子集里做多模态语义检索。支持中文自然语言和以图搜图。默认项目隔离。

入库预检

模拟外包提交。规则层（命名、格式、体积、2 的幂次、面数、glTF 规范）全部用工具算；VLM 可选。结果默认进人工队列，不会自动删除或自动驳回警告项。

人工确认队列

TA 看到规则报告 + VLM 建议 + 预览，作出通过 / 退回 / 申诉通过。原因必填。通过后才进入可检索库。

规范模板：引擎一套，规范可切换

两套模板的命名、面数、贴图上限、必选通道、允许格式都不同。换项目只换 YAML，不改代码。

费用与时延看板

嵌入在本地计算，API 费用为 0，按文件哈希缓存。VLM 按需调用；若未配置 key 则次数为 0。假设单价不会当作实测账单。

离线评测结果

数字全部来自 eval/measure.py 实测。金标查询是自动起草的，需要作者审过才能当作面试口径。
